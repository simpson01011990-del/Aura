# Aura с русским, английским и нидерландским интерфейсом

## Что изменено

- **Язык интерфейса.** В «Настройки → Общие → Язык интерфейса Aura» можно выбрать 简体中文, English, Русский или Nederlands. Язык меняется сразу и сохраняется в `ui.toml`. При первом запуске берётся язык Windows: китайский, русский или нидерландский, для остальных — английский. Установщик тоже показывает китайский, английский, русский и нидерландский в зависимости от языка Windows.
- **Регионы.** Добавлены Россия (`RU`) и Нидерланды (`NL`). В Runtime добавлены их GeoID (203 и 176), а также GeoID уже существующих в списке KR, PH, TR и BO, которых там раньше не хватало.
- **Locale и язык интерфейса профиля.** Добавлены `ru-RU` и `nl-NL`.
- **Часовые пояса.** Добавлены пояса России от Калининграда до Камчатки и Амстердам. После «Определить часовой пояс» российские и нидерландские пояса теперь отображаются и выбираются.

Технически: строки в коде остались на китайском и служат ключами. Перевод делается при отрисовке через `crates/envbox-core/src/i18n.rs` и словарь `crates/envbox-core/src/i18n/dict.rs`. Для строк без перевода показывается китайский оригинал.

## Сборка aura-setup.exe через GitHub Actions (бесплатно, без установки инструментов)

1. Зайдите на GitHub, откройте https://github.com/NGLSL/Aura и нажмите **Fork**.
2. В своём форке загрузите изменённые файлы. Проще всего так: распакуйте `Aura-main-i18n.zip`, затем в форке **Add file → Upload files** и перетащите содержимое папки `Aura-main` с заменой файлов. Либо примените `aura-i18n.patch` командой `git apply aura-i18n.patch`.
3. Откройте вкладку **Actions** и включите workflows для форка.
4. Выберите **Build Windows installer → Run workflow**.
5. Примерно через 20–40 минут в результатах запуска появится артефакт **aura-windows-installer** с `aura-setup.exe` и `aura-setup.exe.sha256`.

## Локальная сборка на Windows

Нужны Rust 1.99.0 (MSVC), Visual Studio Build Tools с C++, CMake, Microsoft Detours (переменная `DETOURS_ROOT`) и NSIS:

```powershell
cargo build --workspace --locked
.\scripts\build-installer.ps1
```

Результат: `artifacts\aura-setup.exe`.

## Замечания

- Версия осталась 0.3.17. Встроенная проверка обновлений будет предлагать официальные версии Aura, в которых этих изменений нет.
- Сборка не подписана, как и официальная.
- Меню в трее переводится при запуске Aura: после смены языка оно обновится при следующем запуске.
